# GameCatalog — Консольный менеджер игровой коллекции

GameCatalog — это приложение для командной строки, которое помогает геймерам вести учёт своей библиотеки игр. Позволяет добавлять игры, отслеживать статус прохождения, хранить жанры и комментарии.

## Возможности
- ✅ Добавление, редактирование и удаление игр
- 🎮 Поддержка статусов: 'wishlist', 'backlog', 'playing', 'paused', 'completed', 'dropped'
- 🏷️ Управление жанрами с проверкой по справочнику
- 💾 Сохранение данных в БД PostgreSQL
- 🔍 Поиск и фильтрация по названию/платформе/статусу (в будущих обновлениях)
- 📊 Статистика по коллекции (в будущих обновлениях)

## Установка

### Требования
- Python 3.14
- PostgreSQL 18

### Шаги установки
#### 1. Установка Python.
Если у вас уже установлен Python, переходите к шагу 2.

Если нет, необходимо сперва его установить. Загрузите установщик Python install manager с официального сайта https://www.python.org/downloads/ и запустите его. Нажмите кнопку Установить Python. Во время установки откроется командная строка. 

Может спросить, увеличить ли лимит длины пути выше 260 символов. Нажимаем Y. 

Может спросить, добавить ли директорию Python в PATH. Нажимаем Y, чтобы добавить путь к интерпретатору в переменные среды.

Если Python не установлен, установщик предложит установить CPython. Нажимаем Y.

После установки будет предложено посмотреть онлайн-помощь, выбираем N, если не нужно.

Проверить, что Python установлен можно командой в адресной строке python --version

#### 2. Установка менеджера пакетов pip.
Если вы устанавливали Python на первом шаге или он у вас уже был установлен, скорее всего у вас уже есть менеджер пакетов pip. Проверить его наличие можно, выполнив в командной строке команду pip --version.
Если pip не установлен мы получим ошибку вида
"pip" не является внутренней или внешней командой, исполняемой программой или пакетным файлом
В таком случае нам необходимо установить pip. командой
python -m ensurepip --upgrade
Если pip был установлен ранее, его можно обновить с помощью команды
python -m pip install --upgrade pip
#### 3. Установка виртуальной среды.
Необязательный пункт, но является рекомендуемым подходом при работе с пакетами Python. Позволяет изолировать пакеты от системных установок Python.
Запустите командную строку в папке, из которой планируете запускать приложение.
Выполните команду ниже. Модулю venv передается название среды, которая в данном случае будет называться "venv1". Вы можете назвать вашу среду как угодно.
python -m venv venv1
Далее для использования её необходимо активировать. Для активации запустите скрипт из папки venv1\Scripts\activate.bat
После активации мы увидим название среды в круглых скобках перед адресом в коммандной строке. После окончания работы со средой её можно деактивировать командой deactivate. Дальнейшие команды предполагают, что виртуальная среда активирована.
#### 4. Установка модуля psycopg для работы с БД PostgreSQL.
Выполните pip install psycopg[binary] для установки модуля psycopg.
#### 5. Установка PostgreSQL.
Загрузите установщик PostgreSQL с официального сайта https://www.postgresql.org/. При разработке использовалась версия 18. Запустите загруженный установщик. Следуйте указаниям установщика. Параметры по умолчанию подходящие. В процессе установки необходимо будет придумать пароль суперпользователя postgres. Запомните этот пароль, он потребуется для подключения к серверу. Остальное тоже можно оставить по умолчанию. Не меняйте порт подключения.

## Использование
### Первичный запуск конфигурационного файла.
В командной строке в каталоге с загруженными файлами выполните команду
python setup_db.py
Выберите пункт настроить базу данных для работы с каталогом игр. (1)
Далее введите название для вашей БД и необходимые параметры подключения - пользователь, пароль и хост. Если вы ничего не меняли в процессе и после установки БД, пользователь по умолчанию - postgres, пароль - ваш пароль. Хост можно оставить пустым, по умолчанию будет использоваться локальный запуск.
Если всё сделали правильно, вы получите сообщение об успехе. Далее можно пользоваться каталогом.
### Изменение конфигурации подключения к БД.
В командной строке в каталоге с загруженными файлами выполните команду
python setup_db.py
Выберите пункт (2). Выберите цифрой, что именно вы хотите изменить, укажите актуальную информацию. Данные не проверяются, только заносятся в файл settings, поэтому используйте внимательно.
### Удаление БД.
В командной строке в каталоге с загруженными файлами выполните команду
python setup_db.py
Выберите пункт (3). Укажите название базы данных, которая больше не нужна. Данные о подключении будут использованы из текущих настроек, при необходимости предварительно обновите их.
### Использование каталога.
Для использования каталога запустите файл run.py, выполнив команду
python run.py
При успешном подключении вы увидите меню программы из 6 пунктов:
1. Добавить игру в каталог.
2. Просмотреть игру по ID.
3. Обновить данные игры.
4. Удалить игру из каталога.
5. Отобразить весь каталог.
0. Выход из программы.
Выберите необходимое вам действие, введя цифру.
#### Добавление игры.
Выбрав пункт 1, укажите последовательно данные добавляемой игры:
- Название.
- Платформу (список допустимых платформ смотрите по ссылке).
- Дату выхода игры в формате YYYY.MM.DD, если день или месяц и день не известны, можно ввести вместо числа xx. Если известен квартал выхода, можно указать дату в формате YYYY.qX, где X - номер квартала.
- Жанры, к которым относится игра. Отделяйте жанры между собой через запятую с пробелом. (Список допустимых для ввода жанров смотрите по ссылке)
- Статус игры в каталоге. Укажите цифрой из предложенных.
- Комментарий. Любой комментарий относительно игры.
После указания данных будет выдано сообщение, что игра успешно добавлена с ID. Если игра с таким ID уже есть в каталоге, повторно добавить её нельзя. ID формируется из первого символа, согласных букв и цифр в названии и платформе. Если вы уверены, что у вас получается 2 игры с одинаковым ID (в названиях отличаются только гласные и спецсимволы, платформы совпадают), попробуйте указать название иначе.
### Просмотр данных об игре
Выбрав пункт 2, укажите ID игры, данные которой необходимо вывести.
### Обновление данных игры
Выбрав пункт 3, укажите ID игры, данные которой необходимо обновить. Программа выведет текущие данные и спросит, какие данные нужно обновить. Выберите цифру и укажите новые данные. Указав актуальные данные выберите +, чтобы применить изменения, или выберите 0, чтобы оставить как было. Если вы обновили несколько полей, но потом передумали изменять одно из них, вы можете ввести вместо новых данных пустую строку, в таком случае поле не будет обновлено.
### Удаление игры из каталога
Выбрав пункт 4, укажите ID игры, которую необходимо удалить из каталога.
### Отображение всего списка игр.
Выберите пункт 5, чтобы отобразить список названий и ID всех игр, добавленных в каталог.
### Выход из программы
Для выхода из программы выберите 0.
